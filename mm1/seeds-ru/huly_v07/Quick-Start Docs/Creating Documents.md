# **Создание тимспейса**

Документы организованы в тимспейсы — они отражают структуру вашей команды. Например, тимспейсы можно назвать «Фичи», «Маркетинг», «Гайдлайны» и т.д.

Чтобы создать тимспейс, нажмите `+`, появляющуюся при наведении на слово «Тимспейсы» в сайдбаре, либо нажмите стрелку рядом с кнопкой `+ Создать документ` и выберите `Создать тимспейс`.

# **Создание документа**

Создать документ можно двумя способами:

Нажмите кнопку `+ Создать документ` в верхней части сайдбара. Откроется диалог с выбором тимспейса; по умолчанию родителем будет последний выбранный тимспейс или документ. Введите название и нажмите `Создать`.

Либо наведите курсор на название тимспейса или любой документ и нажмите появившуюся кнопку `+`. Новый документ автоматически вложится в выбранный тимспейс или документ.

# **Форматирование содержимого**

Документы поддерживают markdown-форматирование. Открыть панель форматирования можно несколькими способами:

* Пишите markdown-синтаксис прямо в документе.
* Используйте плавающую панель инструментов, которая появляется при выделении текста.

С помощью markdown в документ можно добавить заголовки, выделение текста, ссылки, цитаты, нумерованные и маркированные списки, блоки кода.

Изображения, пункты действий, доски для рисования и другие элементы добавляются через `/` или кнопку `+` слева от документа.

# **Обогатите документы @упоминаниями, пунктами действий и совместным редактированием**

Документы напрямую интегрированы с остальной платформой Мудромашина CRM: легко отметить участника команды, назначить пункт действий и сослаться на задачу. Коллеги работают над документом одновременно — не нужно гонять файлы туда-обратно или собираться ради правок.

# **Упоминания**

Отметьте участника команды через @упоминание — он получит уведомление, что его упомянули в документе.

# **Создание пунктов действий**

Создайте пункт действий, набрав `[]` и затем `пробел` на новой строке. Или наберите `/` и выберите `Пункт действий` в выпадающем меню. Появится пустой чекбокс, а при наборе текста слева от него возникнет иконка профиля. Нажмите её и выберите участника — он получит уведомление о назначении и сможет запланировать пункт действий в своём Планировщике.

* [ ] Пункт действий можно назначить в любой момент: наведите курсор на чекбокс и нажмите иконку профиля.
* [ ] Попробуйте назначить эти пункты действий на себя!

# **Совместное редактирование в реальном времени**

Работайте над документами одновременно! Несколько человек могут редактировать и дополнять документ в один момент. Обсуждения ведутся внизу страницы, а любой фрагмент текста можно выделить и оставить встроенный комментарий.
