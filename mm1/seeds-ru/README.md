  label'ы атрибутов, имена ассоциаций, названия тегов

## Механика применения
1. Правки вносятся здесь, коммитятся в platform (ветка mm-crm1-branding).
2. `rbs/scripts/crm1/vm_seed_ru.py` — tar → serial-заливка на VM → `docker cp` в
   `crm-workspace-1:/usr/src/app/init-scripts/` → `docker commit` →
   `mm1/workspace:s0.7.428-mmseed` → swap в docker-compose (workspace + workspace-default).
3. НОВЫЕ воркспейсы получают русский сид автоматически (workspace-инициализатор).
4. Существующий «Демо пространство» русифицирован точечно через API:
   `rbs/scripts/crm1/patch_ws_ru_2510_08.mjs` (+`fix_project_names.mjs`).

## Не переводится (намеренно)
- Имена папок/файлов сидов (внутренние пути, референсы в md-ссылках).
- `script.yaml` (служебный сценарий инициализации, без пользовательских текстов).
- Значения File format (PNG/JPG/…) — технические коды.
- Каналы general/random создаются моделью chunter (не сидами) — в живой демке
  топики переведены через API, в новых воркспейсах останутся EN до пересборки transactor.
